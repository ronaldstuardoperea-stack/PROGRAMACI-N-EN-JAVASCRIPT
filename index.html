Variables

Las variables son contenedores para almacenar información.

Declaración de Variables

Para declarar una variable en JavaScript, se utiliza la palabra clave "let" o "var". Declarar una variable es el proceso de crear un espacio en la memoria para almacenar un valor. Por ejemplo: let nombre; la variable "nombre" ha sido declarada, pero aún no tiene un valor asignado.

Asignación de Variables

Para asignar un valor a una variable, se utiliza el operador de asignación (=). Por ejemplo: nombre = "Juan";

Podemos saludar en la consola usando console.log("Hola "+nombre); Y como resultado obtendremos "Hola Juan" en la consola.

Tipos de Datos

String

Una variable de tipo string es una secuencia de caracteres. Se declara utilizando comillas simples o dobles.

Number

Una variable de tipo number es un valor numérico. Puede ser un número entero o un número decimal.

Boolean

Una variable de tipo boolean es un valor lógico que puede ser verdadero (true) o falso (false). Es útil para tomar decisiones en el código, como en estructuras de control condicionales (if, else).

Null

Una variable de tipo null es un valor especial que representa la ausencia de un valor.

Undefined

Una variable de tipo undefined es un valor que se asigna automáticamente a una variable que ha sido declarada pero no ha sido inicializada.

Bigint

Una variable de tipo bigint es un tipo de dato que permite representar números enteros de gran tamaño.

Symbol

Una variable de tipo symbol es un valor único e immutable que se utiliza comúnmente como identificador para propiedades de objetos.

Operadores Matemáticos

Los operadores matemáticos son símbolos que se utilizan para realizar operaciones matemáticas en JavaScript. Algunos de los operadores matemáticos más comunes son:

Operador Descripción Ejemplo
+ Suma dos números o concatena dos cadenas de texto. 5 + 3 // Resultado: 8
"Hola " + "Mundo" // Resultado: "Hola Mundo"
- Resta dos números. 5 - 3 // Resultado: 2
* Multiplica dos números. 5 * 3 // Resultado: 15
/ Divide dos números. 5 / 3 // Resultado: 1.666...

Operadores de Comparación

Los operadores de comparación son símbolos que se utilizan para comparar dos valores en JavaScript. Algunos de los operadores de comparación más comunes son:

Operador Descripción Ejemplo
> Compara si un valor es mayor que otro. 5 > 3 // Resultado: true
<< /td> Compara si un valor es menor que otro. 5 < 3 // Resultado: false
== Compara si un valor es igual que otro. 5 == 3 // Resultado: false
!= Compara si un valor es diferente que otro. 5 != 3 // Resultado: true

Operadores Lógicos

Los operadores lógicos son símbolos que se utilizan para combinar dos o más expresiones lógicas en JavaScript. Algunos de los operadores lógicos más comunes son:

Operador Descripción Ejemplo
&& Operador lógico AND. Devuelve true si ambas expresiones son verdaderas. (5 > 3) && (2 < 4) // Resultado: true
|| Operador lógico OR. Devuelve true si al menos una de las expresiones es verdadera. (5 > 3) || (2 > 4) // Resultado: true
! Operador lógico NOT. Devuelve true si la expresión es falsa. !(5 > 3) // Resultado: false

Condicionales

Los condicionales son estructuras de control que permiten ejecutar diferentes bloques de código según se cumpla o no una condición.

Condicional If y Else

El condicional If y Else permite ejecutar un bloque de código si se cumple una condición, o otro bloque si no se cumple. Se usan condiciones booleanas para evaluar si una expresión es verdadera o falsa.

Ciclo Switch

El ciclo Switch permite ejecutar diferentes bloques de código según el valor de una variable. podemos optimizar el código utilizando el ciclo Switch en lugar de múltiples condicionales If y Else.

Ciclos

Los ciclos son estructuras de control que permiten ejecutar un bloque de código varias veces.

Ciclo For

El ciclo For permite ejecutar un bloque de código un número específico de veces.

Ciclo While

El ciclo While permite ejecutar un bloque de código mientras se cumpla una condición.

Ciclo Anidado

El ciclo Anidado permite ejecutar un bloque de código dentro de otro bloque de código.

Funciones

Las funciones son bloques de código reutilizables que realizan una tarea específica. DRY (Don't Repeat Yourself) es un principio de programación que promueve la reutilización de código para evitar la duplicación. Las funciones son una herramienta clave para lograr esto, ya que permiten encapsular un bloque de código que realiza una tarea específica y luego reutilizarlo en diferentes partes del programa. Al utilizar funciones, podemos mejorar la legibilidad, mantenibilidad y eficiencia de nuestro código, evitando la repetición innecesaria y facilitando la gestión de cambios futuros.

para ejecutar una función, simplemente se llama por su nombre seguido de paréntesis. Por ejemplo: function saludar() { console.log("Hola, mundo!"); }

Parámetros y Valores de Retorno

Los parámetros son variables que se utilizan para recibir valores cuando se llama a una función. Los valores de retorno son los resultados que una función devuelve después de su ejecución. Por ejemplo: function sumar(a, b) { return a + b; }

Arrays

Los arrays son estructuras de datos que permiten almacenar múltiples valores en una sola variable. Cada valor en un array tiene un índice que indica su posición.

Declaración y Acceso a Elementos

Para declarar un array, se utilizan corchetes []. Para acceder a los elementos de un array, se utiliza el índice del elemento entre corchetes. Por ejemplo: let frutas = ["manzana", "banana", "naranja"]; console.log(frutas[0]); // Resultado: "manzana"

Recorrer un Array dentro de una función

Para recorrer un array dentro de una función, se puede utilizar un ciclo for o el método forEach(). Por ejemplo: function imprimirElementos(array) { for (let i = 0; i < array.length; i++) { console.log(array[i]); } }

Objetos

Los objetos son estructuras de datos que permiten almacenar múltiples valores en una sola variable, donde cada valor tiene un nombre (llave) y un valor asociado.

Por ejemplo:

let persona = {
    nombre: "Juan",
    edad: 30,
    ciudad: "Madrid"
};

En este ejemplo, hemos creado un objeto llamado "persona" con tres propiedades: "nombre", "edad" y "ciudad". Cada propiedad tiene un valor asociado.

Para acceder a las propiedades de un objeto, se utiliza la notación de punto o la notación de corchetes. Por ejemplo:

console.log(persona.nombre); // Resultado: "Juan"

Literales de Objetos y la Notación de Puntos

Los literales de objetos son una forma de crear objetos utilizando una sintaxis más concisa. La notación de puntos es una forma de acceder a las propiedades de un objeto utilizando un punto seguido del nombre de la propiedad.

Literales de Objetos y la Notación de Corchetes

La notación de corchetes es otra forma de acceder a las propiedades de un objeto, utilizando corchetes seguidos del nombre de la propiedad.

console.log(persona["nombre"]); // Resultado: "Juan"

Sintaxis Literales

La sintaxis de literales de objetos es una forma de crear objetos utilizando una sintaxis más concisa. Por ejemplo:

let persona = {
    nombre: "Juan",
    edad: 30,       
    ciudad: "Madrid"
};

Sintaxis Literales

La sintaxis de literales de arreglos es una forma de crear objetos utilizando una sintaxis más concisa. Por ejemplo:

let frutas = ["manzana", "banana", "naranja"];

Si el objeto tiene una propiedad que es una función, se llama método. Por ejemplo:

let persona = {
    nombre: "Juan",
    edad: 30,
    ciudad: "Madrid",
    saludar: function() {
        console.log("Hola, soy " + this.nombre);
    }
};

En este ejemplo, la propiedad "saludar" es un método que imprime un mensaje de saludo utilizando el nombre de la persona.

Metodos Push y Pop

El método push() se utiliza para agregar un nuevo elemento al final de un array, mientras que el método pop() se utiliza para eliminar el último elemento de un array.

let frutas = ["manzana", "banana", "naranja"];
            frutas.push("uva"); // Agrega "uva" al final del array
                console.log(frutas); // Resultado: ["manzana", "banana", "naranja", "uva"]
            frutas.pop(); // Elimina el último elemento del array

Paradigmas de Programación

Programación Funcional

La programación funcional es un paradigma de programación que trata la computación como la evaluación de funciones matemáticas.

Programación Orientada a Objetos

La programación orientada a objetos es un paradigma de programación que organiza el código en torno a objetos y datos.

Scope o Ámbito

El scope o ámbito se refiere al alcance de las variables en un programa. Determina dónde una variable es accesible y cómo se comporta dentro de diferentes bloques de código.

El uso de var, let y const en el scope

En JavaScript, var, let y const son palabras clave utilizadas para declarar variables, y cada una tiene un comportamiento diferente en cuanto al scope:

Palabra Clave Scope Descripción
var Función Las variables declaradas con var tienen un scope de función, lo que significa que son accesibles dentro de la función en la que se declaran, pero no fuera de ella.
let Bloque Las variables declaradas con let tienen un scope de bloque, lo que significa que son accesibles solo dentro del bloque en el que se declaran (por ejemplo, dentro de un if o un for).
const Bloque Las variables declaradas con const también tienen un scope de bloque, pero además son inmutables, lo que significa que su valor no puede ser reasignado después de su declaración.
Consejo Profesional

Usa let si el valor puede cambiar, y const si el valor no puede cambiar después de su declaración.

Programación Orientada a Objetos

La programación orientada a objetos es un paradigma de programación que organiza el código en torno a objetos y datos.

Se basa en el concepto de "objetos", que son instancias de clases que contienen datos y funciones.

Una clase es un molde o plantilla que define las propiedades y métodos que tendrán los objetos de ese tipo.

Las clases se crean utilizando la palabra clave "class". Ejemplo: class Persona { constructor(nombre, edad) { this.nombre = nombre; this.edad = edad; } }

La programación tiene 4 principios fundamentales: encapsulamiento, abstracción, herencia y polimorfismo.

Principio Descripción
Encapsulamiento La capacidad de ocultar los detalles de implementación de un objeto y exponer solo los métodos y propiedades necesarios. Para lograr el encapsulamiento en JavaScript, se pueden utilizar funciones constructoras o clases para definir objetos y sus métodos. Por ejemplo: 
class Persona {
    constructor(nombre, edad) {
        this.nombre = nombre;
        this.edad = edad;
    }
}
Abstracción La capacidad de simplificar la complejidad de un sistema al enfocarse en los aspectos esenciales y ocultar los detalles no esenciales. Por ejemplo, al crear una clase "Vehículo", podemos abstraer los detalles específicos de cada tipo de vehículo y enfocarnos en las propiedades y métodos comunes.
Herencia La capacidad de crear nuevas clases basadas en clases existentes, heredando sus propiedades y métodos. Para establecer herencia en JavaScript, se utiliza la palabra clave "extends". Por ejemplo: class Estudiante extends Persona { }
Polimorfismo La capacidad de un objeto de tomar múltiples formas, permitiendo que un mismo método se comporte de manera diferente según el objeto sobre el que se aplica.

Clases en JavaScript

Las clases en JavaScript son una forma de crear objetos con propiedades y métodos similares.

Se crean utilizando la palabra clave "class" seguida del nombre de la clase. Por ejemplo:

class Persona {
    constructor(nombre, edad) {
        this.nombre = nombre;
        this.edad = edad;
    }
}

En este ejemplo, hemos creado una clase llamada "Persona" con un constructor que recibe dos parámetros: "nombre" y "edad". El constructor se utiliza para inicializar las propiedades del objeto cuando se crea una instancia de la clase.

Para crear una instancia de la clase, se utiliza la palabra clave "new" seguida del nombre de la clase y los argumentos necesarios para el constructor. Por ejemplo:

let persona1 = new Persona("Juan", 30);

En este ejemplo, hemos creado una instancia de la clase "Persona" llamada "persona1" con el nombre "Juan" y la edad 30.

Palabras clave Extends y Super

Nombre Descripción
Extends Se utiliza para crear una clase que hereda de otra clase.
Super Se utiliza para acceder a los métodos y propiedades de la clase padre.

Desestructuración

La desestructuración es una característica de JavaScript que permite extraer valores de arrays o propiedades de objetos de manera más concisa.

let [a, b] = [1, 2];
let { nombre, edad } = { nombre: "Juan", edad: 30 };

Bucle For of

El bucle for...of permite iterar sobre los valores de un objeto iterable.

let frutas = ["manzana", "banana", "naranja"];
for (let fruta of frutas) {
    console.log(fruta);
}

No se puede usar for...of para iterar sobre objetos que no son iterables, como objetos literales. Si se pueda usar for...of para iterar sobre objetos que son iterables, como arrays, strings, maps, sets, etc. Puedes utilizar el hecho de que un bucle for of puede ejecutarse sobre matrices para recorrer objetos.

Metodo Descripción Ejemplo
Object.keys() Devuelve un array con las claves de un objeto. let persona = { nombre: "Juan", edad: 30 }; console.log(Object.keys(persona)); // Resultado: ["nombre", "edad"]
Object.values() Devuelve un array con los valores de un objeto. let persona = { nombre: "Juan", edad: 30 }; console.log(Object.values(persona)); // Resultado: ["Juan", 30]
Object.entries() Devuelve un array de pares clave-valor de un objeto. let persona = { nombre: "Juan", edad: 30 }; console.log(Object.entries(persona)); // Resultado: [["nombre", "Juan"], ["edad", 30]]

Bucle For in

El bucle for...in se utiliza para iterar sobre las propiedades enumerables de un objeto. 

let persona = { nombre: "Juan", edad: 30 };
for (let clave in persona) {
    console.log(clave + ": " + persona[clave]);
}

Resultado:

nombre: Juan

edad: 30

El bucle for...in itera sobre las claves de un objeto, no sobre los valores. Para acceder a los valores, se utiliza la notación de corchetes con la clave.

Literales de Plantillas

Las literales de plantillas son una forma de crear cadenas de texto que pueden contener expresiones embebidas. Se utilizan comillas invertidas (`) para delimitar la cadena y ${} para insertar las expresiones. También permiten crear cadenas de texto multilínea sin necesidad de usar caracteres de escape. Por ejemplo: 

let nombre = "Juan";
let edad = 30;
let mensaje = `Hola, me llamo ${nombre} y tengo ${edad} años.`;
console.log(mensaje); // Resultado: "Hola, me llamo Juan y tengo 30 años."`

Desestructuración de Arreglos

La desestructuración de arreglos es una forma de extraer valores de un array y asignarlos a variables de manera más concisa. Se utilizan corchetes [] para delimitar la estructura de desestructuración. Por ejemplo: 


let frutas = ["manzana", "banana", "naranja"];
let [fruta1, fruta2, fruta3] = frutas;
console.log(fruta1); // Resultado: "manzana"
console.log(fruta2); // Resultado: "banana"
console.log(fruta3); // Resultado: "naranja"

Desestructuración de Arreglo de Arreglos

La desestructuración de arreglo de arreglos es una forma de extraer valores de un array que contiene otros arrays y asignarlos a variables de manera más concisa. Se utilizan corchetes [] para delimitar la estructura de desestructuración. Por ejemplo: 


let matriz = [[1, 2], [3, 4], [5, 6]];
let [[a, b], [c, d], [e, f]] = matriz;
console.log(a); // Resultado: 1
console.log(b); // Resultado: 2
console.log(c); // Resultado: 3
console.log(d); // Resultado: 4
console.log(e); // Resultado: 5
console.log(f); // Resultado: 6

Desestructuración de Objetos

La desestructuración de objetos es una forma de extraer valores de un objeto y asignarlos a variables de manera más concisa. Se utilizan llaves {} para delimitar la estructura de desestructuración. Por ejemplo: 


let persona = { nombre: "Juan", edad: 30, ciudad: "Madrid" };
let { nombre, edad, ciudad } = persona;
console.log(nombre); // Resultado: "Juan"
console.log(edad); // Resultado: 30
console.log(ciudad); // Resultado: "Madrid"
console.log(`Hola, me llamo ${nombre}, tengo ${edad} años y vivo en ${ciudad}.`); // Resultado: "Hola, me llamo Juan, tengo 30 años y vivo en Madrid."

Métodos Incorporados en los arreglos

Los arreglos en JavaScript tienen varios métodos incorporados que permiten realizar operaciones comunes de manera más sencilla. Algunos de los métodos más utilizados son:

Método Descripción Ejemplo
forEach Ejecuta una función para cada elemento del array. 

let frutas = ["manzana", "banana", "naranja"]; 
frutas.forEach((fruta) => console.log(fruta)); 
// Resultado: "manzana", "banana", "naranja"

const nums = [0,10,20,30,40,50];
const result = nums.filter( function(num) {
    return num > 20;
});
console.log(result);
map Crea un nuevo array con los resultados de la llamada a una función proporcionada aplicada a cada elemento del array. 

[0,10,20,30,40,50].map( function(num) {
    return num / 10

console.log(result);
// Resultado: [0, 1, 2, 3, 4, 5]

Operador ... (Spread)

El operador de propagación (...) permite expandir elementos de un array o propiedades de un objeto en lugares donde se esperan múltiples elementos o argumentos. Por ejemplo:


let numeros = [1, 2, 3];
let masNumeros = [...numeros, 4, 5, 6];

En este ejemplo, hemos utilizado el operador de propagación para crear un nuevo array "masNumeros" que contiene los elementos del array "numeros" seguidos de los números 4, 5 y 6.

Operador ... (rest)

El operador de reposo (...) permite capturar múltiples elementos como un array. Por ejemplo:


function sumar(...numeros) {
    return numeros.reduce((a, b) => a + b, 0);
}
console.log(sumar(1, 2, 3, 4, 5));
// Resultado: 15

Modulos en JavaScript

Los módulos en JavaScript son una forma de organizar y reutilizar el código dividiéndolo en archivos separados. Cada archivo puede exportar funciones, objetos o variables que pueden ser importados en otros archivos.

Esto nos permite tener un código más organizado y mantenible. 


                // archivo math.js
                export function sumar(a, b) {
                    return a + b;
                }
                export const PI = 3.14159;

                // archivo main.js
                import { sumar, PI } from './math.js';
                console.log(sumar(2, 3)); // Resultado: 5
                console.log(PI); // Resultado: 3.14159

El DOM (Document Object Model) es una representación estructurada de un documento HTML o XML. Permite a los lenguajes de programación interactuar con el contenido, la estructura y el estilo de un documento web. También permite modificar dinámicamente el contenido y la apariencia de una página web.

Los selectores más comunes son:

Eventos

Los eventos son acciones o sucesos que ocurren en el navegador, como hacer clic en un botón, mover el ratón, presionar una tecla, cargar una página, entre otros. Los eventos permiten a los desarrolladores web crear interactividad y responder a las acciones del usuario.

Los eventos se pueden manejar utilizando funciones llamadas "manejadores de eventos" o "event listeners".

Todos los tipos de eventos son:

Evento Descripción Ejemplo
click Se dispara cuando se hace clic en un elemento. element.addEventListener('click', function() { alert('Elemento clickeado'); });
mouseover Se dispara cuando el puntero del ratón se mueve sobre un elemento. element.addEventListener('mouseover', function() { alert('Mouse sobre el elemento'); });
keydown Se dispara cuando se presiona una tecla en el teclado. document.addEventListener('keydown', function(event) { console.log('Tecla presionada: ' + event.key); });
load Se dispara cuando la página web ha terminado de cargarse. window.addEventListener('load', function() { console.log('Página cargada'); });
submit Se dispara cuando se envía un formulario. form.addEventListener('submit', function(event) { event.preventDefault(); console.log('Formulario enviado'); });
resize Se dispara cuando se cambia el tamaño de la ventana del navegador. window.addEventListener('resize', function() { console.log('Tamaño de ventana cambiado'); });
scroll Se dispara cuando se desplaza la página o un elemento con barra de desplazamiento. window.addEventListener('scroll', function() { console.log('Página desplazada'); });

Hay varias formas de agregar manejadores de eventos a los elementos del DOM.

Pueden ser agregados directamente en el HTML usando atributos como `onclick`, o pueden ser agregados dinámicamente en JavaScript utilizando el método `addEventListener`. por ejemplo:

                const boton = document.getElementById('miBoton');
                boton.addEventListener('click', function() {
                    alert('Botón clickeado');
                });

JSON(Javascript Object Notation)

JSON (JavaScript Object Notation) es un formato de intercambio de datos ligero y fácil de leer y escribir para los humanos, y fácil de analizar y generar para las máquinas. Además, JSON es un subconjunto de la notación literal de objetos de JavaScript, lo que significa que se basa en la misma sintaxis que los objetos de JavaScript.

JSON se utiliza comúnmente para enviar y recibir datos entre un cliente y un servidor en aplicaciones web. Los datos se representan como pares clave-valor, donde las claves son cadenas de texto y los valores pueden ser cadenas, números, booleanos, arrays u objetos.

Ejemplo de un objeto JSON:


                {
                    "nombre": "Juan",
                    "edad": 30,
                    "ciudad": "Madrid",
                    "hobbies": ["fútbol", "lectura", "viajar"],
                    "direccion": {
                        "calle": "Calle Mayor",
                        "numero": 123,
                        "codigoPostal": 28013
                    }
                }

Notación JSON

La notación JSON sigue una estructura específica:

  • Los datos se representan como pares clave-valor, separados por comas.
  • Las claves deben ser cadenas de texto entre comillas dobles.
  • Los valores pueden ser cadenas, números, booleanos, arrays u objetos.
  • Los objetos se delimitan con llaves {} y los arrays con corchetes [].

Ejemplo de un objeto JSON con diferentes tipos de valores:


                    {
                        "nombre": "Juan",
                        "edad": 30,
                        "ciudad": "Madrid",
                        "hobbies": ["fútbol", "lectura", "viajar"],
                        "direccion": {
                            "calle": "Calle Mayor",
                            "numero": 123,
                            "codigoPostal": 28013
                        }
                    }

Convertir JSON a JavaScript y viceversa

Para convertir un objeto JSON a un objeto JavaScript, se utiliza el método `JSON.parse()`. Este método toma una cadena JSON como entrada y devuelve un objeto JavaScript correspondiente.

Ejemplo:


const jsonString = '{"nombre": "Juan", "edad": 30, "ciudad": "Madrid"}';
const objetoJavaScript = JSON.parse(jsonString);
console.log(objetoJavaScript.nombre); // Resultado: "Juan"
console.log(objetoJavaScript.edad); // Resultado: 30
console.log(objetoJavaScript.ciudad); // Resultado: "Madrid"

Ahora para convertir un objeto JavaScript a una cadena JSON, se utiliza el método `JSON.stringify()`. Este método toma un objeto JavaScript como entrada y devuelve una cadena JSON correspondiente.

Ejemplo:


const objetoJavaScript = { nombre: "Juan", edad: 30, ciudad: "Madrid" };
const jsonString = JSON.stringify(objetoJavaScript);
console.log(jsonString); // Resultado: '{"nombre":"Juan","edad":30,"ciudad":"Madrid"}'

Testing

El testing es el proceso de evaluar un sistema o sus componentes para determinar si cumple con los requisitos especificados y funciona correctamente. El objetivo del testing es identificar errores, defectos o problemas en el software antes de que sea entregado a los usuarios finales.

JEST

Jest es un framework de pruebas de JavaScript desarrollado por Facebook. Se utiliza principalmente para probar aplicaciones web y bibliotecas de JavaScript, especialmente aquellas construidas con React. Jest proporciona una forma sencilla y eficiente de escribir pruebas unitarias, pruebas de integración y pruebas de extremo a extremo.

Función Expect

La función expect() es una función proporcionada por Jest que se utiliza para realizar afirmaciones (assertions) en las pruebas. Permite verificar si un valor cumple con ciertas condiciones o expectativas.

La función expect() se utiliza junto con los matchers, que son métodos que definen las condiciones que se esperan cumplir. Algunos matchers comunes son:

  • toBe(): Verifica si un valor es exactamente igual a otro.
  • toEqual(): Verifica si un valor es igual a otro, considerando la igualdad profunda.
  • toBeTruthy(): Verifica si un valor es verdadero (truthy).
  • toBeFalsy(): Verifica si un valor es falso (falsy).
  • toContain(): Verifica si un array o string contiene un elemento específico.
  • toHaveLength(): Verifica si un array o string tiene una longitud específica.

Tipos de Pruebas

Existen varios tipos de pruebas que se pueden realizar en el desarrollo de software. Algunos de los tipos más comunes son:

Tipo de Prueba Descripción Framework de Pruebas
Pruebas Unitarias Se enfocan en probar componentes individuales del software de forma aislada. Jest, Mocha, Jasmine
Pruebas de Integración Se utilizan para verificar que los componentes integrados funcionen correctamente juntos. React Testing Library, Enzyme
Pruebas de Extremo a Extremo Evalúan el comportamiento del sistema completo desde la perspectiva del usuario final. Webdriver JS, Cypress y Protractor

Librerías de Pruebas

Librería Descripción Enlace

Mocking

El mocking es una técnica utilizada en pruebas de software para simular el comportamiento de dependencias externas o componentes que no están disponibles durante la ejecución de las pruebas. Permite crear objetos simulados (mocks) que imitan el comportamiento de los objetos reales, lo que facilita la prueba de unidades de código de manera aislada.
