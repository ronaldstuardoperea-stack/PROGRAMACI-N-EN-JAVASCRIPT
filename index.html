Variables

Las variables son contenedores para almacenar información.

Declaración de Variables

Para declarar una variable en JavaScript, se utiliza la palabra clave "let" o "var". Declarar una variable es el proceso de crear un espacio en la memoria para almacenar un valor. Por ejemplo: let nombre; la variable "nombre" ha sido declarada, pero aún no tiene un valor asignado.

Asignación de Variables

Para asignar un valor a una variable, se utiliza el operador de asignación (=). Por ejemplo: nombre = "Juan";

Podemos saludar en la consola usando console.log("Hola "+nombre); Y como resultado obtendremos "Hola Juan" en la consola.

Tipos de Datos

String

Una variable de tipo string es una secuencia de caracteres. Se declara utilizando comillas simples o dobles.

Number

Una variable de tipo number es un valor numérico. Puede ser un número entero o un número decimal.

Boolean

Una variable de tipo boolean es un valor lógico que puede ser verdadero (true) o falso (false). Es útil para tomar decisiones en el código, como en estructuras de control condicionales (if, else).

Null

Una variable de tipo null es un valor especial que representa la ausencia de un valor.

Undefined

Una variable de tipo undefined es un valor que se asigna automáticamente a una variable que ha sido declarada pero no ha sido inicializada.

Bigint

Una variable de tipo bigint es un tipo de dato que permite representar números enteros de gran tamaño.

Symbol

Una variable de tipo symbol es un valor único e immutable que se utiliza comúnmente como identificador para propiedades de objetos.

Operadores Matemáticos

Los operadores matemáticos son símbolos que se utilizan para realizar operaciones matemáticas en JavaScript. Algunos de los operadores matemáticos más comunes son:

Operador Descripción Ejemplo
+ Suma dos números o concatena dos cadenas de texto. 5 + 3 // Resultado: 8
"Hola " + "Mundo" // Resultado: "Hola Mundo"
- Resta dos números. 5 - 3 // Resultado: 2
* Multiplica dos números. 5 * 3 // Resultado: 15
/ Divide dos números. 5 / 3 // Resultado: 1.666...

Operadores de Comparación

Los operadores de comparación son símbolos que se utilizan para comparar dos valores en JavaScript. Algunos de los operadores de comparación más comunes son:

Operador Descripción Ejemplo
> Compara si un valor es mayor que otro. 5 > 3 // Resultado: true
<< /td> Compara si un valor es menor que otro. 5 < 3 // Resultado: false
== Compara si un valor es igual que otro. 5 == 3 // Resultado: false
!= Compara si un valor es diferente que otro. 5 != 3 // Resultado: true

Operadores Lógicos

Los operadores lógicos son símbolos que se utilizan para combinar dos o más expresiones lógicas en JavaScript. Algunos de los operadores lógicos más comunes son:

Operador Descripción Ejemplo
&& Operador lógico AND. Devuelve true si ambas expresiones son verdaderas. (5 > 3) && (2 < 4) // Resultado: true
|| Operador lógico OR. Devuelve true si al menos una de las expresiones es verdadera. (5 > 3) || (2 > 4) // Resultado: true
! Operador lógico NOT. Devuelve true si la expresión es falsa. !(5 > 3) // Resultado: false

Condicionales

Los condicionales son estructuras de control que permiten ejecutar diferentes bloques de código según se cumpla o no una condición.

Condicional If y Else

El condicional If y Else permite ejecutar un bloque de código si se cumple una condición, o otro bloque si no se cumple. Se usan condiciones booleanas para evaluar si una expresión es verdadera o falsa.

Ciclo Switch

El ciclo Switch permite ejecutar diferentes bloques de código según el valor de una variable. podemos optimizar el código utilizando el ciclo Switch en lugar de múltiples condicionales If y Else.

Ciclos

Los ciclos son estructuras de control que permiten ejecutar un bloque de código varias veces.

Ciclo For

El ciclo For permite ejecutar un bloque de código un número específico de veces.

Ciclo While

El ciclo While permite ejecutar un bloque de código mientras se cumpla una condición.

Ciclo Anidado

El ciclo Anidado permite ejecutar un bloque de código dentro de otro bloque de código.

Funciones

Las funciones son bloques de código reutilizables que realizan una tarea específica. DRY (Don't Repeat Yourself) es un principio de programación que promueve la reutilización de código para evitar la duplicación. Las funciones son una herramienta clave para lograr esto, ya que permiten encapsular un bloque de código que realiza una tarea específica y luego reutilizarlo en diferentes partes del programa. Al utilizar funciones, podemos mejorar la legibilidad, mantenibilidad y eficiencia de nuestro código, evitando la repetición innecesaria y facilitando la gestión de cambios futuros.

para ejecutar una función, simplemente se llama por su nombre seguido de paréntesis. Por ejemplo: function saludar() { console.log("Hola, mundo!"); }

Parámetros y Valores de Retorno

Los parámetros son variables que se utilizan para recibir valores cuando se llama a una función. Los valores de retorno son los resultados que una función devuelve después de su ejecución. Por ejemplo: function sumar(a, b) { return a + b; }

Arrays

Los arrays son estructuras de datos que permiten almacenar múltiples valores en una sola variable. Cada valor en un array tiene un índice que indica su posición.

Declaración y Acceso a Elementos

Para declarar un array, se utilizan corchetes []. Para acceder a los elementos de un array, se utiliza el índice del elemento entre corchetes. Por ejemplo: let frutas = ["manzana", "banana", "naranja"]; console.log(frutas[0]); // Resultado: "manzana"

Recorrer un Array dentro de una función

Para recorrer un array dentro de una función, se puede utilizar un ciclo for o el método forEach(). Por ejemplo: function imprimirElementos(array) { for (let i = 0; i < array.length; i++) { console.log(array[i]); } }

Un ejemplo más completo, utilizando parametros para word y match.

function buscarPalabra(word, match) {

                            console.log("La palabra " + match + " se encuentra en la posición " + i + ".");
                        }else {
                            console.log("La palabra " + match + " no se encuentra en la posición " + i + ".");
                        }

Objetos

Los objetos son estructuras de datos que permiten almacenar múltiples valores en una sola variable, donde cada valor tiene un nombre (llave) y un valor asociado.

Por ejemplo:

let persona = {
    nombre: "Juan",
    edad: 30,
    ciudad: "Madrid"
};

En este ejemplo, hemos creado un objeto llamado "persona" con tres propiedades: "nombre", "edad" y "ciudad". Cada propiedad tiene un valor asociado.

Para acceder a las propiedades de un objeto, se utiliza la notación de punto o la notación de corchetes. Por ejemplo:

console.log(persona.nombre); // Resultado: "Juan"

Literales de Objetos y la Notación de Puntos

Los literales de objetos son una forma de crear objetos utilizando una sintaxis más concisa. La notación de puntos es una forma de acceder a las propiedades de un objeto utilizando un punto seguido del nombre de la propiedad.

Literales de Objetos y la Notación de Corchetes

La notación de corchetes es otra forma de acceder a las propiedades de un objeto, utilizando corchetes seguidos del nombre de la propiedad.

console.log(persona["nombre"]); // Resultado: "Juan"

Sintaxis Literales

La sintaxis de literales de objetos es una forma de crear objetos utilizando una sintaxis más concisa. Por ejemplo:

let persona = {
    nombre: "Juan",
    edad: 30,       
    ciudad: "Madrid"
};

Sintaxis Literales

La sintaxis de literales de arreglos es una forma de crear objetos utilizando una sintaxis más concisa. Por ejemplo:

let frutas = ["manzana", "banana", "naranja"];

Si el objeto tiene una propiedad que es una función, se llama método. Por ejemplo:

let persona = {
    nombre: "Juan",
    edad: 30,
    ciudad: "Madrid",
    saludar: function() {
        console.log("Hola, soy " + this.nombre);
    }
};

En este ejemplo, la propiedad "saludar" es un método que imprime un mensaje de saludo utilizando el nombre de la persona.

Metodos Push y Pop

El método push() se utiliza para agregar un nuevo elemento al final de un array, mientras que el método pop() se utiliza para eliminar el último elemento de un array.

let frutas = ["manzana", "banana", "naranja"];
            frutas.push("uva"); // Agrega "uva" al final del array
                console.log(frutas); // Resultado: ["manzana", "banana", "naranja", "uva"]
            frutas.pop(); // Elimina el último elemento del array
                console.log(frutas); // Resultado: ["manzana", "banana", "naranja"]

Objeto Math

El objeto Math es un objeto incorporado en JavaScript que proporciona propiedades y métodos para realizar operaciones matemáticas. Algunas de las propiedades y métodos más comunes del objeto Math son:

Propiedad/Método Descripción Ejemplo
Math.PI Devuelve el valor de π (pi). Math.PI // Resultado: 3.141592653589793
Math.E Devuelve el valor de e (base del logaritmo natural). Math.E // Resultado: 2.718281828459045
Math.abs(x) Devuelve el valor absoluto de x. Math.abs(-5) // Resultado: 5
Math.max(a, b) Devuelve el mayor de dos números. Math.max(3, 7) // Resultado: 7
Math.min(a, b) Devuelve el menor de dos números. Math.min(3, 7) // Resultado: 3
Math.random() Devuelve un número aleatorio entre 0 y 1. Math.random() // Resultado: un número entre 0 y 1

Métodos de Redondeo

El objeto Math también proporciona métodos para redondear números. Algunos de los métodos de redondeo más comunes son:

Método Descripción Ejemplo
Math.round(x) Redondea x al entero más cercano. Math.round(3.5) // Resultado: 4
Math.ceil(x) Redondea x hacia arriba al entero más cercano. Math.ceil(3.2) // Resultado: 4
Math.floor(x) Redondea x hacia abajo al entero más cercano. Math.floor(3.8) // Resultado: 3
Math.trunc(x) Elimina la parte decimal de x, dejando solo la parte entera. Math.trunc(3.9) // Resultado: 3

Métodos de Potenciación y Raíz Cuadrada

El objeto Math también proporciona métodos para realizar operaciones de potenciación y raíz cuadrada. Algunos de los métodos más comunes son:

Método Descripción Ejemplo
Math.pow(base, exponente) Devuelve base elevado a la potencia de exponente. Math.pow(2, 3) // Resultado: 8
Math.sqrt(x) Devuelve la raíz cuadrada de x. Math.sqrt(16) // Resultado: 4

Métodos de String

El objeto String en JavaScript proporciona varios métodos para manipular cadenas de texto. Algunos de los métodos más comunes son:

Método Descripción Ejemplo
String.length Devuelve la longitud de la cadena. "Hola".length // Resultado: 4
String.charAt(index) Devuelve el carácter en la posición especificada. "Hola".charAt(0) // Resultado: "H"
String.concat(str1, str2, ...) Combina dos o más cadenas y devuelve la cadena resultante. "Hola".concat(" Mundo") // Resultado: "Hola Mundo"
String.indexOf(substring) Devuelve la posición de la primera ocurrencia de la subcadena. "Hola".indexOf("o") // Resultado: 1
String.lastIndexOf(substring) Devuelve la posición de la última ocurrencia de la subcadena. "Hola".lastIndexOf("o") // Resultado: 1
String.toUpperCase() Devuelve la cadena en mayúsculas. "Hola".toUpperCase() // Resultado: "HOLA"
String.toLowerCase() Devuelve la cadena en minúsculas. "HOLA".toLowerCase() // Resultado: "hola"

Operador typeof

El operador typeof se utiliza para obtener el tipo de dato de una variable o expresión en JavaScript. Devuelve una cadena que indica el tipo de dato. Algunos de los tipos de datos que typeof puede devolver son:

Tipo de Dato Descripción Ejemplo
string Indica que la variable es una cadena de texto. typeof "Hola" // Resultado: "string"
number Indica que la variable es un número. typeof 42 // Resultado: "number"
boolean Indica que la variable es un valor lógico (true o false). typeof true // Resultado: "boolean"
object Indica que la variable es un objeto (incluyendo arrays y null). typeof { nombre: "Juan" } // Resultado: "object"
function Indica que la variable es una función. typeof function() {} // Resultado: "function"

Error

Un error es un problema que impide que un programa se ejecute correctamente.

Bug

Un bug es un defecto en el código que causa un comportamiento no deseado o incorrecto. Sin embargo el codigo puede ejecutarse, pero no produce el resultado esperado.

Tipo de Error Descripción Ejemplo
Sintaxis Ocurre cuando el código no sigue las reglas de sintaxis de JavaScript. let x = 5 // Falta el punto y coma al final de la línea
Referencia Ocurre cuando se intenta acceder a una variable que no ha sido declarada. console.log(y); // y no ha sido declarada previamente
Tipo Ocurre cuando se intenta realizar una operación con un tipo de dato incompatible. let z = "5" + 3; // Resultado: "53" (concatenación en lugar de suma)

Declaraciones Throw, Try y Catch

Declaración Descripción Ejemplo
throw Se utiliza para lanzar un error personalizado. throw new Error("Mensaje de error");
try Se utiliza para intentar ejecutar un bloque de código. try { // Código que puede lanzar un error } catch (error) { // Manejo del error }
catch Se utiliza para capturar y manejar los errores que ocurren en el bloque try. try { // Código que puede lanzar un error } catch (error) { // Manejo del error }

Tipos de Empty Values

Tipo Descripción Ejemplo
Empty Strings Representa la ausencia de un valor. let x = "";
null Representa la ausencia de un valor de manera intencional. let x = null;
undefined Representa la ausencia de un valor asignado a una variable. let y; console.log(y); // Resultado: undefined

Paradigmas de Programación

Programación Funcional

La programación funcional es un paradigma de programación que trata la computación como la evaluación de funciones matemáticas.

Programación Orientada a Objetos

La programación orientada a objetos es un paradigma de programación que organiza el código en torno a objetos y datos.
